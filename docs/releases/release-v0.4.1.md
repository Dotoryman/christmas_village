# Christmas Village 0.4.1

Sweep the foreground snow to stir a short-lived cloud of powder. Drawn lines have
been removed so the original artwork stays clean. Outdoor snowfall is denser,
with 360 layered flakes instead of 135.

The README now introduces the experience first. Development instructions live
in a separate guide, effect modules are grouped, and code is formatted and commented.
Unused duplicate artwork and stale screenshots are removed from the current
tree; original PNGs remain in earlier source archives and Git history.

Validation: mobile/desktop interaction checks, web build and offline bundle checks.
The iOS source includes the updated offline page. Native Xcode/WKWebView execution
is not verified on Windows.
