# Christmas Village v0.2.0

휴대폰 세로 화면에서 즐기는 작은 크리스마스 마을의 첫 공개 버전입니다.

- 눈 내리는 오두막과 따뜻한 실내, 클릭·터치로 반응하는 조명과 소품.
- 눈의 깊이·바람, 지붕 눈 입자, 벽난로 불빛, 코코아 김과 부드러운 장면 전환.
- 화면에는 텍스트·헤더·푸터가 없으며 키보드와 움직임 줄이기를 지원합니다.
- 웹용 경량 에셋과 오프라인 실행용 SwiftUI/WKWebView iOS 프로젝트.
- 한글·영어 README, 스크린샷, 이미지 생성 기록, MIT 라이선스.

서비스: https://christmasvillage.cloud/

웹 배포와 모바일·데스크톱 Chromium 테스트, 네트워크를 차단한 iOS HTML 번들
검사를 완료했습니다. Xcode 빌드와 iOS 실기기 검증은 아직 수행하지 않았습니다.

압축 파일: `web`은 웹 배포 결과물, `ios`는 Xcode 소스와 오프라인 번들,
`source`는 전체 프로젝트 소스입니다. iOS 앱의 설치 파일(IPA)은 포함하지 않습니다.

태그 기반 GitHub Actions 검증을 제공합니다. CI 자동 배포는 Cloudflare용 저장소
시크릿 설정 후 활성화됩니다. 이번 배포는 인증된 로컬 Wrangler로 완료했습니다.
