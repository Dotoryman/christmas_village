# Christmas Village 0.5.0

Come in for a Christmas feast. Touch the little living-room table to visit a new
candlelit scene filled with roast turkey, gingerbread, a yule log and festive
table settings. Warm the cocoa or candlelight, then touch the open archway to
return to the fireplace.

The original scene style, image-only interface and portrait layout are preserved.
Room light states and wiped frost survive the visit. Keyboard, reduced motion,
muted-by-default sound and offline iOS source are supported.

Validation: 14 mobile/desktop browser checks, web build and offline page checks.
Native Xcode/WKWebView execution is not verified on Windows.
