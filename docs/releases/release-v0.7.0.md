# Christmas Village 0.7.0

Touch the crystal glass for a brief rim glint and a quiet chime, discover gold
sparkles above the little table gift, and tend the fire for rising embers.
Sound remains muted until explicitly enabled, with bounded tone playback and
automatic audio-node cleanup. Decorative particles respect reduced motion.

Image-save context menus, image dragging and Safari/iOS touch callouts are
suppressed while existing hold and wipe gestures remain available. Public image
data and screenshots cannot be fully copy-protected by a browser interface.

Validation: 20 mobile/desktop browser tests, web and offline bundle checks.
Native iOS/Safari execution is not verified on Windows.
