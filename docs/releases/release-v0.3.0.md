# Christmas Village v0.3.0

A little more life in the winter village.

- A white Arctic fox walks across the snow, leaving gently fading pawprints.
  Touch the foreground path to invite it again.
- Watch for shooting stars, or touch the moon to make a wish.
- Softer snow, gentle gusts, chimney smoke, window snowfall, curling cocoa steam
  and warm floating dust add movement without visible interface text.
- Flame-only fire shimmer and a gift bow that glows in place.
- Cached lighting textures, reduced-motion support and background-tab pausing.

Live: https://christmasvillage.cloud/

Browser interaction checks and offline iOS bundle checks run before automatic
Cloudflare deployment. Native Xcode and device testing remain unverified.
Archives contain web output, full source and an offline Xcode project, not an IPA.
