# Christmas Village 0.3.1

The original illustrated winter scenes remain the focus. This release removes
the fox and adds quieter environmental motion: gentle outer-pine sway, snow
released by touching branches, slow star shimmer, and roof snow falling in small
staggered clumps. Smoke and cocoa steam are softer, with fewer fireplace embers.

The interface remains image-only, with English accessible names, keyboard
operation and system reduced motion. The iOS source includes the updated offline
web bundle. No experimental 3D scene is included.

Validation: mobile and desktop browser tests, web build and offline bundle checks.
Xcode, physical iPhone and WKWebView execution are not verified on Windows.
