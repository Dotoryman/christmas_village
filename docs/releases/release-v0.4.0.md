# Christmas Village 0.4.0

Four small winter interactions join the original illustrated scenes:

- Rub the cabin window to clear frost from the glass. Frost slowly returns.
- Draw on the foreground snow. New snow gradually covers the marks.
- Hold either tree to light it from bottom to top, ending at the star. Short taps
  continue to switch the lights normally.
- Use the speaker icon for original synthesized wind, snow crunch and fireplace
  ambience. Sound is initially muted and pauses in the background.

No visible explanatory text, accounts or external audio downloads. Keyboard
alternatives are included. Reduced motion keeps drawing and wiping interactive,
freezes automatic recovery and immediately completes tree illumination.

The iOS source includes the same self-contained offline experience. Mobile and
desktop Chromium checks cover drawing, wiping, touch hold, audio activation and
muting, along with existing interactions. Offline checks cover all four features.
Xcode, physical iPhone and native WKWebView execution remain unverified on Windows.
